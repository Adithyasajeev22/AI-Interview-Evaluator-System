# 🤖 AI Interview Evaluator System

An AI-powered interview evaluation platform that analyzes candidate responses using Natural Language Processing (NLP) techniques. The system evaluates communication skills, grammar, sentiment, keyword relevance, and answer similarity to generate detailed performance reports and feedback.

---

## 📌 Project Overview

The AI Interview Evaluator System is designed to automate the interview assessment process by analyzing candidates' textual responses. It leverages NLP techniques to evaluate answer quality, identify key concepts, measure similarity with expected answers, analyze sentiment, and assess grammar. The application also generates evaluation reports, making the interview process more efficient, objective, and data-driven.

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/Adithyasajeev22/AI-Interview-Evaluator-System.git
```

### Navigate to the project

```bash
cd AI-Interview-Evaluator-System
```

### Create a virtual environment

```bash
python -m venv env
```

### Activate the environment

Windows

```bash
env\Scripts\activate
```

Linux / macOS

```bash
source env/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
streamlit run app.py
```
